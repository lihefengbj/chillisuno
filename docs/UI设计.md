# UI 设计

## 1. 整体布局

```
┌────────────────────────────────────────────────┐
│ 侧边栏导航          │  主内容区                  │
│ ┌──────────┐      │                              │
│ │ 账户      │      │  （随导航切换）              │
│ │ 曲库      │      │                              │
│ │ 下载中心  │      │                              │
│ │ 上传      │      │                              │
│ │ 设置      │      │                              │
│ └──────────┘      │                              │
├────────────────────────────────────────────────┤
│ 播放条：封面 | 曲名/艺人 | 播放控制 | 进度 | 音量 │  (M2)
└────────────────────────────────────────────────┘
```

- 深色主题（音乐软件惯例），Qt StyleSheet 实现
- 侧边栏固定宽度 180px，QListWidget + QStackedWidget 切换页面

## 2. 页面

### 账户（M1）

登录状态（头像/邮箱）、剩余额度、登录/退出/刷新额度按钮。
登录通过弹出内嵌浏览器窗口完成，登录成功自动关闭。

### 曲库（M2）

- 顶部：搜索框、筛选（收藏/全部）、刷新
- 列表：封面缩略图、标题、风格标签、时长、收藏按钮
- 双击播放，播放时底部出现播放条

### 下载中心（M3）

- 下载队列表格：曲名、进度、速度、状态、操作（暂停/取消/打开目录）
- 批量入口：从曲库多选加入队列
- 归档设置：目录模板 `{风格}/{标题}.{扩展名}`

### 上传（M4）

- 文件拖入区、混淆强度档位（关/低/中/高）
- 处理后指纹自测提示，确认后上传

### 设置

下载目录、并发数、主题、混淆默认档位。
