## 音频混淆管道（M4 详述）

目标：周期性地改写波形的时间序列特征（保留听感），规避上传指纹检测。

```
本地文件 → 解码(soundfile/miniaudio)
  → 同音替换：矩形分块频域保留幅度、替换相位（numpy）
  → 块边界相位最小范数求解保证连续（numpy）
  → 指纹自测（矩形分块幅度谱，24 频段中位数二值化）
  → 上传
```

强度做成可调档位，默认保守。混淆用于规避检测存在封号风险，仅限个人实验。
