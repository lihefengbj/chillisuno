# 里程碑计划

| 里程碑 | 内容 | 验收标准 |
|---|---|---|
| M1 账户 | 工程骨架、内嵌浏览器登录/退出、会话保持、credits 显示 | 登录后显示邮箱与额度，重启应用保持登录 |
| M2 曲库 | 作品列表拉取、搜索、收藏、在线播放 + 底部播放条 | 能浏览并播放自己账号的歌曲 |
| M3 下载中心 | 单曲/批量下载、队列、断点续传、本地归档 | 批量下载 20 首无失败，目录按规则归档 |
| M4 上传 + 混淆 | 本地音频上传；混淆管道（时域/频域/重压缩扰动），强度档位可调 | 上传成功；混淆前后指纹自测有对比 |
| M5 创作 | 提交生成任务、进度轮询、结果入库 | 应用内发起生成并收到结果 |
| M6 打包 | PyInstaller → Windows exe / macOS app | 双平台安装包可运行 |

## 音频混淆管道（M4 详述）

目标：周期性改变声纹波形的时间序列特征，规避上传指纹检测。

```
本地文件 → 解码(soundfile)
  → 时域：微变速/时间拉伸（librosa）
  → 频域：EQ/相位微扰（scipy.signal）
  → 重压缩：重采样 + MP3↔WAV 编解码往返
  → 指纹自测（chromaprint/dejavu，可选）
  → 上传
```

强度做成可调档位，默认保守。混淆用于规避检测存在封号风险，仅限个人实验。
