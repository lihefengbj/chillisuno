# 打包发布

## 工具

PyInstaller（Windows 与 macOS 分别在各自系统上原生构建；macOS 的 Intel 和 Apple Silicon 也分别构建，无可靠交叉编译）。
打包配置：[chillisuno.spec](../chillisuno.spec)。

## CI 自动构建（GitHub Actions）

工作流：[.github/workflows/build.yml](../.github/workflows/build.yml)

| 触发 | 行为 |
|---|---|
| push 到 main | Windows、macOS Intel（x86_64）和 Apple Silicon（arm64）构建验证，产物存为 artifact（保留供下载测试） |
| 打 tag `v*`（如 `git tag v0.1.0 && git push --tags`） | 构建 + 自动创建 GitHub Release，附 Windows zip、macOS Intel dmg 和 Apple Silicon dmg |
| 手动 workflow_dispatch | 同 push |

- tag 构建时自动把版本号注入 `app/version.py`（默认 `0.1.0-dev`）
- macOS 的 `icon.icns` 在 CI runner 上用 iconutil 从 logo.png 生成
- macOS 当前**无签名**：用户首次打开需"右键→打开"；对外分发需
  Apple Developer 证书 + 公证（把证书存入仓库 Secrets 后在 CI 签名）

## 本地手动打包

```bash
pip install pyinstaller
python tools/make_logo.py        # 重新生成图标（含 icon.ico）
pyinstaller --noconfirm chillisuno.spec
```

- Windows 产物：`dist/chillisuno/`（已验证可运行，含 QtWebEngineProcess）
- macOS 产物：`dist/chillisuno.app`（在对应架构的 Mac 上构建）
- Intel Mac 下载 `chillisuno-macos-x86_64.dmg`；Apple Silicon Mac 下载 `chillisuno-macos-arm64.dmg`

## 体积优化

- 当前 Windows 产物约 556MB（QWebEngine 占大头）
- 可在 spec 的 `excludes` 去掉未用 Qt 模块（Qt3D、QtCharts、QtQml 等）
- M4 引入 librosa 后体积会显著增大，届时评估是否按需加载

## 用户数据位置

- Windows: `%APPDATA%/chillisuno/`（WebEngine profile、SQLite）
- macOS: `~/Library/Application Support/chillisuno/`
