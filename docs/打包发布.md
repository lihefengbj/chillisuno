# 打包发布

## 工具

PyInstaller（双平台在各自系统上分别构建，无可靠交叉编译）。

## Windows

```bash
pyinstaller --noconfirm --windowed --name "chillisuno" \
  --icon assets/icon.ico main.py
```

产物 `dist/chillisuno/`，用 NSIS 或 Inno Setup 制成安装包。

注意：QWebEngine 依赖随 PySide6 自动收集，但需确认
`QtWebEngineProcess.exe` 与 resources/translations 被包含。

## macOS

```bash
pyinstaller --noconfirm --windowed --name "chillisuno" \
  --icon assets/icon.icns main.py
```

产物 `dist/chillisuno.app`，打包为 DMG 分发。
对外分发需 Apple Developer 签名 + 公证（notarization），否则用户需
"右键打开"绕过 Gatekeeper。

## 体积优化

- `exclude-module` 去掉未用的 Qt 模块（Qt3D、QtCharts 等）
- M4 引入 librosa 后体积会显著增大，届时评估是否按需加载

## 用户数据位置

- Windows: `%APPDATA%/chillisuno/`（WebEngine profile、SQLite）
- macOS: `~/Library/Application Support/chillisuno/`
